# Kong API Gateway Configuration

This directory contains the declarative configuration files for **Kong API Gateway (v3.6)** running in DB-less mode.

## Files

- `kong.yml`: Declarative configuration for the Keycloak IdP stack (`docker-compose.keycloak-kong.yml`).
- `kong.zitadel.yml`: Declarative configuration for the ZITADEL IdP stack (`docker-compose.zitadel.yml`).
