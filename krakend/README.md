# KrakenD API Gateway Configuration

This directory contains the declarative configuration files for **KrakenD API Gateway (v2.7)**.

## Files

- `krakend.json`: Declarative configuration for the Keycloak IdP stack (`docker-compose.krakend.yml` / `docker-compose.yml`).
- `krakend.zitadel.json`: Declarative configuration for the ZITADEL IdP stack (`docker-compose.zitadel.yml`).
